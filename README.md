# Studio Eliá Design — site

Site institucional do Studio Eliá Design, publicado com GitHub Pages.

## Estrutura

- `index.html` — site público (sobre, serviços, cases, processo, contato)
- `*.png` — logos e ícone da marca

## Contatos

Preencha Instagram, WhatsApp e e-mail no objeto `CONTATO`, no final do `index.html`. Botões vazios não aparecem no site.

## Publicar alterações

No VS Code: aba Controle do Código-Fonte → escreva uma mensagem → **Confirmar (Commit)** → **Sincronizar alterações**. O GitHub Pages atualiza o site em 1 a 2 minutos.
